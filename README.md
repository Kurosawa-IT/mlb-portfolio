# MLB投球・打球データの分析と翌年ERA予測

MLBの実データを用いて、投球条件と空振り、打球条件と本塁打の関係を分析し、当年成績から翌年ERAを予測しました。データ取得・前処理・探索的分析・統計的分析・モデル比較を実装し、時系列で分離したテストデータで評価しています。

空振りと本塁打では、非線形な関係を扱うRandom Forestが定数確率のベースラインを上回りました。翌年ERAでは前年ERAの持越しより誤差が小さくなった一方、平均予測に対する改善は明確ではありませんでした。予測時点と対象集団を明示し、各結果の適用範囲を検討しています。

分析実行日：2026-10-31。文書更新日：2026-11-01。

## 背景と3つの問い

野球の指標は、予測する時点と対象集団によって意味が変わります。本プロジェクトでは、投球・打球後の条件付き結果推定と、翌年成績という将来予測を区別し、精度の高さだけでなく「どの範囲なら説明できるか」を検討しました。

| テーマ | 問いと位置付け | 実行済みNotebook |
|---|---|---|
| 空振り | 実際の球種・球速・投球位置・カウント・投打左右と空振りの関連。スイングされた球に条件付ける | [① 空振り](notebooks/01_whiff.ipynb) |
| 本塁打 | 打球速度・角度の組合せから打球後の本塁打確率を推定 | [② 本塁打](notebooks/02_hr.ipynb) |
| 翌年ERA | 当年成績だけで翌年ERAを予測し、前年ERA持越しを超えられるか | [③ ERA](notebooks/03_era.ipynb) |

## 使用データと対象

- **Statcast / Baseball Savant、2025-04-01〜05-31**：全61日、234,985球。レギュラーシーズンのみ。
- 空振り：バントを除くスイング110,368球、空振り率22.82%。`swinging_strike`・`swinging_strike_blocked`・`swinging_pitchout`を空振りと定義。接触は`foul`・`foul_tip`・`hit_into_play`・`foul_pitchout`。見逃し・バントは除外し、foul_tipは接触に含めます。
- 本塁打：`hit_into_play` 41,310球から、打球速度・角度・結果の欠損152球を除いた41,158球。本塁打率4.15%。打席前予測ではありません。
- **FanGraphs、2018〜2025年**：6,736投手シーズン。`IDfg`×連続年で結合し、移籍や同姓同名に名前を使いません。当年20IP以上の3,602投手年のうち、翌年ERAが観測された3,006投手年を分析。596件の翌年非観測を0で補完しません。規定投球回で絞りません。

取得は原則pybaseball。FanGraphsの旧HTML経路が空応答になったため、同サイトのランキング用JSONに切替えました。取得ログ・件数・SHA256を保存し、再実行はローカルParquetを利用します。[出典と利用条件](DATA_SOURCES.md)を参照してください。生データはGit管理対象外です。

## 評価方法と主要結果

分類は4月を訓練、5月1〜15日を検証、16〜31日を固定テストに使用。ERAは目的年2019〜2022年を訓練、2023年を検証、2024〜2025年を固定テストに使用しました。前処理はPipeline内で訓練データだけから学習します。検証log loss／RMSEで選択したモデルを固定し、テスト結果による再選択は行っていません。

| 固定テスト | 選択モデル | ベースライン | 結果 |
|---|---|---|---|
| 空振り 29,771球 | RF、葉20 | 訓練陽性率の定数確率 | log loss **0.441 vs 0.532**、ROC-AUC **0.768**、AP **0.560** |
| 本塁打 11,132球 | RF、葉50 | 訓練陽性率の定数確率 | log loss **0.063 vs 0.171**、ROC-AUC **0.982**、AP **0.711** |
| 翌年ERA 901投手年 | RF、葉50 | 前年ERA持越し | RMSE **3.452 vs 3.653**、MAE **1.736 vs 1.854** |

APはaverage precision。Accuracyだけで判断すると本塁打の定数モデルでも95.9%となるため、確率の質と陽性クラスの評価を重視しました。全指標・検証実験は [空振りCSV](reports/whiff_experiments.csv)、[本塁打CSV](reports/hr_experiments.csv)、[ERA CSV](reports/era_experiments.csv) に保存しています。

試合／投手単位の対応付きブートストラップによる、選択モデル−ベースラインの損失差95%区間は、空振りlog loss **−0.096〜−0.086**、本塁打 **−0.118〜−0.098**、ERA RMSE（前年ERA比）**−0.314〜−0.140**でした。これは固定モデルのテスト標本に対する区間で、学習や年度の不確実性すべてを表しません。

## モデル改善と比較実験

- 空振り：基本ロジスティック→球速×高さ・回転・変化量の追加で検証log loss **0.505→0.484**。非線形のRFで**0.437**。葉を20から50に増やすと**0.441**で改善せず、葉20を選択。
- 本塁打：速度・角度の線形ロジスティックに二乗・積を追加し、検証log loss **0.107→0.070**。RF葉50で**0.062**。角度の非単調性を表すことが有効でした。
- ERA：ERAのみのRidgeの検証RMSE **2.644**から、FIP・WHIP・K/9・BB/9等を加えて**2.600**。RF葉20は**2.603**で上回れず、葉50は**2.573**。複雑さを増やせば必ず良くなる結果ではありません。

## 解釈と限界

空振り率はスライダー31.3%、フォーシーム18.2%、シンカー11.9%でした。ただし球種・位置・投手能力・スイング選択が混ざった集計で、球種変更の因果効果ではありません。球速帯の単純比較も球種構成の影響を受けます。訓練GLMでは球速×高さの交互作用も確認しました。

本塁打は105〜110mph・20〜30度の領域で72.2%（478/662、記述用Wilson 95%区間68.7〜75.5%）。速度だけでなく適した角度との組合せが重要です。球場・方向・天候を含まず、同じ速度・角度でも結果は変わります。

ERAは前年持越しを改善しましたが、**訓練平均だけでもテストRMSEは3.503**です。平均比の差の95%区間は−0.092〜+0.002で0を含み、追加価値は限定的です。翌年1アウトだけでERA81となった投手も含まれ、極端値がRMSEを左右しました。翌年IPで事後的に対象を絞らず、この難しさを結果として残しています。翌年非登板、20IP閾値、2020短縮年の選択バイアスもあります。

統計モデルは訓練データのみで推定し、試合／投手でcluster robust標準誤差を計算。係数と区間は探索的な関連として解釈します。別年度への外部検証、未知選手への評価、欠損がランダムであること、完全な交絡調整は未検証です。詳しくは [日本語分析レポート](reports/REPORT.md) と [事前設計](reports/DESIGN.md) を参照してください。

## 再現方法

Python 3.11以上（今回の実行環境はWindows・Python 3.12.14）。リポジトリルートから実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python -m pip install --no-deps -e .
python -m pytest -q
python run.py --phase all
```

macOS/Linuxでは仮想環境の有効化を `source .venv/bin/activate` に変更します。ロックファイルは今回の環境の全依存を記録しています。OS固有パッケージはマーカーで除外しています。異なるPythonで依存解決ができない場合は `requirements.txt` を使用しますが、バージョン差による数値の一致は保証しません。

`python run.py --phase whiff` / `hr` / `era` で個別実行できます。初回はインターネット接続が必要で、取得に数分以上かかります。既存キャッシュは再取得しません。Notebookを直接開く場合もリポジトリルートを作業ディレクトリにしてください。Notebook内に実行済みの表・図があるため、GitHub上では再取得せず閲覧できます。
